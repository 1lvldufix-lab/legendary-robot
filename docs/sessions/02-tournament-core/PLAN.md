# Сессия 2 — Турнирное ядро (меню-бот)

**Читай перед началом:** `docs/plans/05-tournament-bot.md` (разделы 1, 3, 3b, 3c, 8), `docs/plans/00-architecture.md` (принципы 0–3).

## Задачи
- [ ] Нижнее меню (стиль елобота): Турниры | Мой Клуб | Долги | Репорт | Настройки | Связь | Админ | Помощь.
- [ ] Регистрация игрока по /start, заявка в клуб, назначение клуба админом (условие «Мой Клуб» в аппе).
- [ ] **Турнир на клубах:** матчи/таблица/Elo — на клубах, игрок сидит в клубе (принцип 0 в 00-АРХИТЕКТУРА).
- [ ] Дивизионы 1–5 + привязка чатов (`group_chat_id` как у оригинала).
- [ ] Сезон/турнир: создание, туры, статусы туров (open/locked/played).
- [ ] **Туры в двух режимах** (настройка сезона): `manual` (админ создаёт пары/жеребьёвкой, как в елоботе) и заглушка-интерфейс под `challenge_place` (сам парсер — сессия 7). Переключение режима в настройках.
- [ ] Генерация календаря тура в ручном режиме (расписание из elobot `tournament.py`), дедлайны матчей.
- [ ] **Замены игроков** в клубе: меняется только связь игрок↔клуб, кошелёк игрока и Elo клуба не трогаются (раздел 3b в 05).
- [ ] **Права вручную:** root из env раздаёт турнирного админа/капитана командой бота (3c).
- [ ] Таблица дивизиона: очки/мячи, PNG-рендер для канала (standings_image из елобота).

## Файлы (ориентир)
`bot/handlers/menu.py`, `bot/handlers/clubs.py`, `bot/handlers/replace.py`, `bot/tournament_schedule.py`, `bot/standings.py`.

## Критерий готовности
Создать сезон → 2 дивизиона → назначить клубы → сгенерировать тур (manual) → таблица считается и постится в чат; замена игрока не меняет балансы и очки.
