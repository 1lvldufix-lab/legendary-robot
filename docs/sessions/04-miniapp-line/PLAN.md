# Сессия 4 — Мини-апп: перенос фронта, Линия и Турнир

**Читай перед началом:** `docs/plans/01-miniapp-features.md` (разделы 0, 1, 3), `../logovo-copy/OVERVIEW.md`.

## Задачи
- [ ] Скопировать фронт из `../../logovo-copy/src/` в `../../miniapp/static/` (index.html + js + css), поменять брендинг.
- [ ] Подключить к нашему API: `/api/bootstrap`, `/api/wallet`, `/api/divisions`, `/api/matches`, `/api/standings` — форматы совместимы с образцами в `../../logovo-copy/src/api-samples/`.
- [ ] Генератор кэфов виртуальной лиги: Elo клубов + форма + домашнее преимущество + маржа (config.ODDS_MARGIN_PCT) → таблица `markets` + `odds_history`.
- [ ] Экран «Линия»: вкладки дивизионов, карточки матчей, «Все рынки (15+)» (модалка из ui.js).
- [ ] Экран «Турнир»: таблица 16 клубов.

## Критерий готовности
Мини-апп открывается с валидным initData, Линия и Турнир показывают матчи/таблицу из НАШЕЙ БД, кэфы сгенерированы нами.
