# Сессия 5 — Ставки: купон, экспресс, расчёт

**Читай перед началом:** `docs/plans/01-miniapp-features.md` (разделы 0, 8), `docs/plans/02-reuse-base.md` (движок Дракобета).

## Задачи
- [ ] POST `/api/predictions`: атомарная ставка по образцу save_bet из Дракобета (FOR UPDATE → списание → insert), баланс-журнал.
- [ ] Лимиты из bootstrap (min/max/макс выплата/6 открытых/exposure) — сервер проверяет, не только фронт.
- [ ] Экспресс 2–10 ног, void-нога делит итоговый кэф (анти-эксплойт Дракобета).
- [ ] Расчёт: джоба по подтверждённым матчам → рынки → won/lost/void → уведомление игроку.
- [ ] Показ истории: `/api/predictions?status=` + карточка купона + фильтры (экран «Купоны»).
- [ ] Экран «ставка принята» (bet-accepted) и модалка «кэф изменился».

## Критерий готовности
Ставка ординар и экспресс проходит, баланс списывается, после подтверждения матча купоны рассчитались, игроку прилетело уведомление.
