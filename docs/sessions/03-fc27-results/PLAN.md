# Сессия 3 — Результаты матчей + OCR FC27

**Читай перед началом:** `docs/plans/06-fc27-parsing.md` (главный документ), `docs/plans/02-reuse-base.md` (ocr.py елобота).

## Задачи
- [ ] Приём 1–3 скринов FC27 от капитана (handle_photo каркас из елобота).
- [ ] Новый промпт по схеме JSON из 06-ПАРСИНГ-FC27 (шапка/счёт/таймер/пенальти/игроки/warnings), few-shot на примерах из `../samples/fc27-screens/`.
- [ ] Правила: счёт только из шапки; голы — дедуп по имени по всем скринам; валидация «сумма Г ≤ счёт».
- [ ] Карточка подтверждения: игрок → соперник → админ (цепочка статусов pending/reported/confirmed).
- [ ] Ручной ввод при провале OCR (форма: счёт + авторы из состава клубов).
- [ ] Финализация: Elo (elo.py) + таблица + `match_goals` (опция «бомбардиры» у создателя турнира).
- [ ] Откат/правка результата (revert_match из match_processor) + audit log.

## Тесты
Прогнать все 11 скринов из `../samples/fc27-screens/` через промпт, сверить JSON, кейс 120:00+пенальти обязателен.

## Критерий готовности
Скрин FC27 → распознан → обе стороны подтвердили → Elo и таблица обновились → результат виден в `/api/matches`.
