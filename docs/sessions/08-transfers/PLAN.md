# Сессия 8 — Трансферы, бюджет, калькулятор

**Читай перед началом:** `docs/plans/05-tournament-bot.md` (разделы 4, 5).

## Задачи
- [ ] Заявка трансфера капитаном: игрок, сумма, клуб-покупатель → подтверждение обеих сторон → одобрение админа.
- [ ] Трансферное окно: открыто/закрыто (настройка сезона), лимит трансферов за окно.
- [ ] Проверки: нельзя в свой клуб, нельзя превысить бюджет, игрок не «заблокирован».
- [ ] Движение бюджетов клубов (доходы/расходы) + журнал.
- [ ] Калькулятор бюджета: карточка «бюджет + доходы − расходы − долги», симулятор перед покупкой.
- [ ] **Трансферы — отдельная полноэкранная страница в аппе** (не окошко): лента заявок, история переходов, суммы, статусы, кто одобрил — всё публично проверяемо (см. docs/plans/08, B2).
- [ ] Пост в канал после одобрения. (Аукцион трансферов — сессия 12, не здесь.)

## Критерий готовности
Полный цикл: заявка → подтверждения → одобрение → бюджеты изменились → пост в канале → видно в аппе.
