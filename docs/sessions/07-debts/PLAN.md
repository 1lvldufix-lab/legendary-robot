# Сессия 7 — Challenge Place: автоскан, долги, напоминания

**Читай перед началом:** `docs/plans/07-challenge-place.md` (главный документ), `docs/plans/05-tournament-bot.md` (раздел 3).

## Задачи
- [ ] РЕКОН: получить ссылку на реальный тур у пользователя → проверить HTML/сеть сайта (открытые JSON? защита?) → выбрать способ парсинга.
- [ ] Парсер: календарь тура → `matches` + дедлайны; таблица → сверка; результаты → импорт `reported`.
- [ ] Долги: не сыграл / не внёс / счёт разошёлся → `debts` + ТП 0:3 (walkover).
- [ ] Пост «Долги по турам» в канал дивизиона.
- [ ] Напоминания 3×/день (08:00/12:00/18:00 МСК) с тегами должников + троттлинг (reminder_log).
- [ ] Команда админа `/scan` + автоскан по расписанию; алерт админу при падении сайта/смене вёрстки.

## Критерий готовности
Ссылка на тур → календарь в БД → после тура пост с долгами → напоминания приходят 3 раза в день.
