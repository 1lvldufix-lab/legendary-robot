# Сессия 10 — Полировка и деплой

**Читай перед началом:** `планы/03-УЛУЧШЕНИЯ-ПРОТИВ-ОРИГИНАЛА.md` (весь), `планы/00-АРХИТЕКТУРА.md`.

## Задачи
- [ ] Cashout (квота + кнопка в купоне), value-метки на «отъехавшие» кэфы, лайв-центр.
- [ ] Страница «Правила» в аппе, финальный брендинг/палитра (сдвиг от золотого оригинала).
- [ ] Push-уведомления ботом: ставка, расчёт, дедлайн, трансфер, долг.
- [ ] Деплой: Railway/VPS + Docker (из елобота), домен вместо Cloudflare-туннеля, кнопка меню-аппа.
- [ ] Бэкапы БД по расписанию в ЛС админам (db_export) + восстановление из ZIP (из Дракобета).
- [ ] Неделя наблюдения: логи, ошибки, правки.

## Критерий готовности
Система живёт на своём домене, игроки ставят через апп, админы рулят — неделя без ручного вмешательства.
