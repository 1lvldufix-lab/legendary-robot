# ПЛАН 10 — ФУЛЛ-ПРОХОД: весь проект за один заход (старт по «го» в новой сессии)

Владелец запускает «го» → выполнение идёт НЕПРЕРЫВНО сверху вниз, без вопросов
и остановок. Все развилки УЖЕ решены — канон в `планы/09-РЕШЕНИЯ-ВЛАДЕЛЬЦА-2026-09-24.md`
(читать первым!). Сомнение → брать дефолт из 09, помечать комментом в коде
`# per план 09`, идти дальше. Коммит после каждого блока. Остановки — только
из списка «Где физически нужен владелец» (внизу).

Общие правила: валидатор initData + окно auth_date 24 ч на ВСЕХ эндпоинтах;
всё регулируемое — в bot_settings; publication — только ЛС; язык — русский;
клубы — реальные команды FC (лого из logovo-copy/src/assets/logos).

---

## Блок 0 — Инфраструктура (починка запуска)
- venv в корне проекта: `python3 -m venv venv`, `pip install -r бот/requirements.txt`
  (asyncpg из requirements УБРАТЬ; добавить psycopg2-binary).
- `бот/config.py`: `load_dotenv(папка файла/.env)`; дефолты: `WEBAPP_PORT=9542`,
  `START_BALANCE=422`, `CLUB_START_BUDGET=20_000_000`, плюс новые настройки
  (порог сделки 2М, штраф 1М, окно оспаривания 24 ч, бонус-серия, XP, маржа 5%).
- `.env`: `WEBAPP_PORT=9542` (ADMIN_IDS=6163072393 уже вписан); `.env.example` синхронизировать.
- `миниапп/server.py`: standalone-режим не выходит сразу (`web.run_app`).
**Gate:** `python миниапп/server.py` живёт на 9542, `/api/bootstrap` без initData → 401.
**Коммит 1.**

## Блок 1 — Схема БД (полная, по плану 00 + решения 09)
- `club_players` (player_id, club_id, роль владелец/участник, дата) — UNIQUE(player_id)
  = один клуб на человека; замены не трогают балансы.
- `tournaments`: + `format` (league/ЛЧ/ЛЕ/ЛК), + `tour_mode` (manual/challenge_place),
  + `rounds` (1/2), + `tour_days` (длительность тура, кастом создателя).
- `reminder_log`: PK → (tournament_id, kind, date). `challenge_links`: + tournament_id.
- `users.balance` default 422; + `is_frozen`/`freeze_reason` (бан-заморозка по 09).
- `promo_codes` (code, amount, max_activations, deadline) + `promo_activations`.
- `user_streaks` (user_id, streak_days, last_bonus_date) — бонус-серия 50→+10→кап 150.
- `transfers`: + player_id, + tournament_id. `divisions` — контейнер при лиге (создатель
  разводит 1..N). Индексы.
- `бот/elo.py`: ранги от 1000-базиса — Окурок <1050, Пепел 1050–1149, Сигарета
  1150–1249, Сигара 1250–1399, Легенда ≥1400; формула/K-факторы не трогать.
**Gate:** smoke-скрипт: все таблицы создаются идемпотентно (SQLite /tmp + главный путь).
**Коммит 2.**

## Блок 2 — Авторизация и каркас API
- Валидатор initData: HMAC b"WebAppData" + **проверка auth_date (окно 24 ч → 401)**.
- `/api/bootstrap` (юзер с балансом/лимитами/is_admin + дивизионы), `/api/wallet`;
  заглушка `static/index.html` (логотип текстом KURILKA SIGARKI).
- Замороженный юзер: 403 «Доступ закрыт» с причиной (решения бьют фичи).
**Gate:** curl с самоподписанным initData → юзер создаётся (баланс 422); битая подпись
→ 401; старый auth_date → 401.
**Коммит 3.**

## Блок 3 — Бот: каркас и меню
- `main.py`: logging, error handler, JobQueue; `/start` → игрок в `players` + запрос
  game_nickname (для OCR-сопоставления).
- Нижнее меню (план 05): Турниры | Мой Клуб | Долги | Репорт | Настройки | Связь |
  Админ | Помощь — заготовки колбеков, flesh в блоках 4–10.
**Gate:** getMe ок; smoke зелёный; (живой /start — см. «остановки»).
**Коммит 4.**

## Блок 4 — Турнирное ядро (сессия 2)
- Создание сезона (root-команда): лига-контейнер → дивизионы 1..N, формат
  (лига/ЛЧ/ЛЕ/ЛК), tour_mode (manual/challenge_place), rounds (1/2), tour_days.
- Клубы: реальные FC-команды + лого; выдача клуба root-командой; `club_players`
  пишет владельца; бюджет 20М. Заявка «Запросить клуб» из аппа → ЛС root.
- Календарь: авто round-robin (N−1 туров × rounds), жеребьёвка кубков ботом;
  правка пар до открытия тура. Таблица дивизиона: очки/И/В/Н/П/мячи.
**Gate:** сезон создан → календарь сгенерён → таблица считается на фейковых данных.
**Коммит 5.**

## Блок 5 — Результаты и Elo (сессия 3)
- Репорт: владелец кидает скрин боту → OCR-каскад (план 06: OpenRouter VL → Groq →
  Gemini → NIM → OCR.space → tesseract; счёт из шапки, голы дедупом, пенальти в скобках,
  бомбардиры по тумблеру создателя) → **финализация СРАЗУ, без подтверждения** (09).
- Оспаривание: соперник командой бота в окне 24 ч → статус «спорный» → судья
  (tournament_admins) решает; ставки заморожены. Несыгранный: висит доигрываться,
  тур НЕ блокирует, следующий открывается по расписанию; штраф-долг 1М (регулируемый).
- Ручной ввод при провале OCR (счёт + авторы из состава). Дедуп `processed_screenshots`.
- Финализация: Elo (tournament_elo), таблица, `match_goals`.
**Gate:** 11 эталонов «Нова тека» прогнаны через промпт, кейс 120:00+пенальти обязателен.
**Коммит 6.**

## Блок 6 — Мини-апп: фронт, ядро экранов (сессии 4–6)
- Портируем фронт оригинала (`logovo-copy/src/`) на наш `/static`; контракт ~64
  эндпоинта из api.js. Бренд KURILKA SIGARKI, валюта «дым», только русский.
  Палитра-пресеты (уголь+оранж дефолт; варианты показать владельцу в конце прохода).
- Экраны ядра: линия (базовые рынки, избранное) → карточка матча (форма W/D/L,
  история кэфов) → купон → кабинет (дым/XP/уровень/звание/история ставок/уведомления)
  → мой клуб (состав/бюджет/заявка) → таблицы/дивизионы.
- «Мой клуб» без клуба: «Клуба нет» + кнопка «Запросить клуб».
**Gate:** все экраны ядра открываются на тестовых данных (скриншоты в отчёт).
**Коммит 7.**

## Блок 7 — Ставки (сессии 4–5)
- Маркеты: 1х2, тоталы (ТБ/ТМ), БТТС, ИТБ, AH; кэфы из Elo + маржа 5% (публично);
  `odds_history` — публичная история движения.
- Купон: single/экспресс до 5 ног; авто-обрез потенциальной выплаты под max_payout
  (видно ДО подтверждения); лимиты оригинала (10/50 000/10 000/6 купонов/exposure 20 000);
  **серверная сверка кэфа** → ODDS_CHANGED (модель оригинала, проверена стресс-тестом);
  idempotency_key от фронта.
- Расчёт: авто при финализации матча (bets_settle) + кнопка перерасчёта админу;
  void = возврат + уведомление с причиной.
- Кубок: ставки принимаются — рынки на каждую игру серии + рынок исхода
  противостояния (2:0/2:1/1:2/0:2; можно вторым этапом в этом же блоке).
- Запреты: владелец не ставит на свой клуб; админ/судья — на судимые матчи
  (купон их скрывает).
- Прогрессия: XP 100 за выигрыш купона; уровень N = N×500 XP; звания
  Окурок→Пепел→Сигарета→Сигара→Легенда.
- Экономика дыма: бонус за серию входов (50, +10/день, кап 150, сброс пропуском);
  промокоды (админ-код: сумма/активации/дедлайн; ввод в кабинете).
- Уведомления: бот — турнирное (дедлайн, долг, трансфер, спор); апп-центр —
  апп-события (ставка принята, рассчитана, ODDS_CHANGED, бонус/промокод).
**Gate:** ординар и экспресс ставятся и рассчитываются; ODDS_CHANGED работает;
запреты владелец/судья работают; бонус-серия и промокод работают.
**Коммит 8.**

## Блок 8 — Трансферы (сессии 6/8)
- Маркетплейс: лот (фикс/аукцион), поиск по позиции/рейтингу; сделка авто при
  деньгах до порога 2М, выше — одобрение судьи; комиссия 5% сгорает.
- Свободные агенты: цена = рейтинг² × K (K в админке). Состав без лимита.
- Обмены: деньги / игрок+деньги / игрок↔игрок. Баланс клуба виден на экране
  трансферов. Полноэкранный экран трансферов.
**Gate:** сделка проходит, комиссия сгорает, порог уводит крупную сделку к судье.
**Коммит 9.**

## Блок 9 — Долги + Challenge Place (сессия 7)
- Напоминания 3×/день (08:00/12:00/18:00 МСК) — ЛС должникам; `reminder_log` по дате.
- Парсер Challenge Place: headless-браузер → открыть ссылку тура → regex
  `window.__INITIAL_STATE__` → JSON: competitors/матчи (homeScore/awayScore)/сетки →
  сопоставление с `matches`/`clubs`; `/scan` по команде; расхождения → алерт root;
  всё импортное помечено источником (откатимо). Иерархия stage→round→series.
**Gate:** парсер на тестовой ссылке (план 07) возвращает 31 competitor и 3 матча.
**Коммит 10.**

## Блок 10 — Админка (сессия 9)
- Апп-панель по users.is_admin (контракт из admin.js, план 09-админка): dashboard,
  bets+void, limits, markets+action, **pause (глобально/матч)**, players+adjust/ban
  (бан = заморозка с причиной, баланс цел), риск/exposure, audit-log.
- Root-команды бота: выдать/снять судью (tournament_admins), выдать клуб, промокод.
**Gate:** void → возврат+причина; пауза закрывает купон; ban → 403 с причиной; audit пишется.
**Коммит 11.**

## Блок 11 — Тесты и финиш
- `тесты/smoke.py` полный: схема, валидатор (позитив/негатив/auth_date), bootstrap,
  ставка→расчёт→void, трансфер→комиссия, парсер CP на сохранённом HTML-фикстуре.
- Тестовые данные: скрипт — 8–10 фейковых клубов (реальные лого), матчи, кэфы,
  ставки; отдельный скрипт сноса.
- Деплой на VPS — ОТДЕЛЬНО по команде владельца (не в этом проходе); локально
  всё работает на 127.0.0.1:9542.
**Gate:** полный smoke зелёный; скриншоты ядра в финальном отчёте. **Коммит 12.**
