# ПЛАН ФУНКЦИЙ ТУРНИРНОГО БОТА (меню-бот «Логово Фифарей»)

Это половина системы рядом с мини-аппом: всё, что делается в чатах и ЛС.
Референсы: меню-каркас и кроны из елобота, дисциплина транзакций из Дракобета.

## Роли
- **Игрок** — участник лиги, привязан к клубу.
- **Капитан клуба** — заявляет трансферы, вводит результаты своего клуба.
- **Админ турнира** — одобрения, долги, принудительные решения, рассылки.
- **Создатель турнира** — настройки формата (например, считать ли бомбардиров со скринов).

## 1. Привязка и профиль
- `/start` → регистрация игрока (players), привязка telegram_id.
- Заявка в клуб: игрок выбирает клуб из списка свободных → капитан/админ подтверждает.
- Назначение клуба админом (в оригинале это условие открытия «Мой Клуб» в аппе).
- Профиль: ник в игре, клуб, дивизион, Elo, форма.

## 2. Результаты матчей (FC27 Mobile)
- Кнопка «📝 Ввести результат» в ЛС бота при предстоящем матче.
- ⚡ Авто-ввод: 1–3 скрина статистики FC27 → OCR (каскад провайдеров из елобота,
  промпт ПЕРЕПИСАТЬ под экраны FC27; поле «бомбардиры» — опция создателя турнира).
- Распознано → карточка подтверждения: счёт, голы, ассисты → «✅ Всё верно» /
  «❌ Ошибка» → правка руками (форма: счёт + авторы из состава клубов).
- Подтверждение соперником (кнопка) → финализация → Elo (elo.py) + таблица + апп.
- Ручной режим: «не удалось распознать» → форма без ИИ (это убирает фрустрацию оригинала
  «⚠️ Не удалось автоматически распознать результат со скриншотов»).
- Дедлайны: DM за N часов + авто-ТП (шаблон job_deadline_check из елобота).

## 3. Туры — два режима на выбор (настройка сезона)
- **Режим `challenge_place`:** туры создаются автоматически парсером с сайта
  (календарь, дедлайны, результаты — см. 07-CHALLENGE-PLACE.md).
- **Режим `manual`:** туры ведёт админ прямо в боте, как в елоботе: создать тур,
  назначить пары (вручную или жеребьёвкой), дедлайны, закрыть тур.
- Переключение режима — в настройках сезона; уже внесённые матчи сохраняются.
- В обоих режимах результат вносится одинаково: скрины FC27 → OCR (раздел 2).

## 3a. Долги
- Режим ЧП: парсер ссылки на тур → таблица результатов → сверка с нашими матчами
  → расхождения = долги (не сыграл / не выставил счёт).
- Ручной режим: долги из дедлайнов (просрочил — долг) + ставит админ командой.
- БД `debts`: клуб, сумма (или «штраф»), причина, источник, статус.
- Пост в канал «Долги по турам» после парса/закрытия тура.
- Напоминания 3×/день (08:00, 12:00, 18:00 МСК): тег игроков с открытыми долгами
  (шаблон job_reminders + reminder_log для троттлинга — из елобота).
- Админ: «оплатил/простил» → статус, журнал (audit log).

## 3b. Замены (обязательная функция)
- Замена игрока в клубе: админ/капитан указывает «вышел ↔ вошёл» → обновляется
  ТОЛЬКО связь игрок↔клуб (состав клуба).
- **Кошелёк не трогается:** монеты, XP, ставки, история остаются у игрока
  (принцип 1 в 00-АРХИТЕКТУРА). Клуб не теряет Elo и очки — они на клубе.
- Открытые ставки заменённого игрока рассчитываются как обычно.
- Замена фиксируется в audit log + пост в чат дивизиона.
- Каркас замен в турнире есть в елоботе (`/replace_player`) — берём логику,
  переписываем под клубную привязку.

## 3c. Права
- Root-админы — только из `ADMIN_IDS` (env).
- Турнирный админ / капитан клуба выдаётся и снимается root-ом вручную командой
  бота (никакой автоматики по чат-правам). Всё в `tournament_admins` + audit log.

## 4. Трансферы
- Заявка капитана: «продаю <игрок> за N в <клуб>» → обе стороны подтверждают в боте
  → админ одобряет → движение бюджетов, запись в `transfers` + пост в канал.
- Трансферное окно: открыто/закрыто (настройка сезона).
- Анти-дурка: нельзя купить в свой же клуб, нельзя превысить бюджет, лимит трансферов за окно.

## 5. Калькулятор бюджета
- У клуба: бюджет + доходы (призовые, продажи) − расходы (покупки, штрафы, долги).
- Команда «бюджет» → карточка с раскладкой (из `balance_history` клубов).
- Симулятор перед трансфером: «если купим за N — останется M, хватит ли на штрафы».

## 6. Связь с админом
- Кнопка «🐞 Связь» → сообщение пересылается админам с кнопкой «ответить»
  (каркас из елобота handlers; в оригинале это единственная фича их бота — у нас тоже будет).

## 7. Джобы (планировщик PTB)
| Джоба | Расписание | Что делает |
|---|---|---|
| debt_reminders | 08:00 / 12:00 / 18:00 МСК | посты+ЛС по долгам |
| deadline_check | каждые 15 мин | DM о дедлайнах матчей, авто-ТП |
| tour_rotate | по расписанию сезона | закрыть тур, открыть следующий, пересчитать кэфы |
| bets_settle | после подтверждения матчей | расчёт купонов мини-аппа (движок Дракобета) |
| daily_backup | раз в сутки | экспорт БД админам (db_export.py елобота) |

## 8. Меню (нижняя клавиатура, стиль елобота)
🏆 Турниры | ⚽ Мой Клуб (результат, состав, трансферы, бюджет) | 💰 Долги |
📨 Репорт | 🔧 Настройки | 🐞 Связь | 👮 Админ | ℹ️ Помощь

## 9. Чего не делаем в боте
- Ставки на реальный футбол (SStats) — отдельная история, не в этом боте.
- Казино/игры Казимира.
- Elo-турниры «по парам» из елобота как отдельный режим (у нас лига клубов); модуль
  оставляем в коде на будущее.
