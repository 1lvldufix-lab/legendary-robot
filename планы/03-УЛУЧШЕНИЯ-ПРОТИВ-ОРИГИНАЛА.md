# ЧТО ДЕЛАЕМ ЛУЧШЕ ОРИГИНАЛА (и что продумываем сами)

Оригинал: фронт хороший, бэкенд наружу не виден и писался «как получилось».
Ниже — отличия клона, чтобы это был не форк-копия, а наша система.

## 1. Бэкенд — проектируем с нуля (у оригинала его просто нет в доступе)
- aiohttp API в одном процессе с ботом (оригинал: py-сервер + туннель Cloudflare —
  у нас нормальный хост, без временных туннелей).
- Все денежные операции в транзакциях, журнал `balance_history` (кто, когда, сколько, за что).
- Идемпотентные миграции в коде (как у Дракобета: `ALTER ... IF NOT EXISTS`), без «ручных бампов».
- `/api/*` пагинация и ETag-кэш для тяжёлых списков (оригинал шлёт 124 КБ на `/api/matches`).

## 2. Генератор кэфов — своя математика
- Кэфы на матчи виртуальной лиги считаем из Elo клубов (elo.py) + домашнее преимущество
  + форма последних 5 + маржа из админки (формула Дракобета `_apply_margin`).
- История кэфов в `odds_history` → живой экран «движение кэфов» (renderOddsMovers
  у оригинала есть в коде, но, судя по всему, не был сделан до конца).
- Value-подсветка: если кэф «отъехал» от расчётного — метка (/API intelligence/value).

## 3. Экспресс включаем (в оригинале залочен)
- 2–10 событий, произведение кэфов, void-нога делит итоговый кэф (анти-эксплойт Дракобета),
  общий лимит выплаты.

## 4. Cashout — выкуп ставки до матча
- Квота = остаточная стоимость по времени и статусу ноги; кнопка в карточке купона.
- У оригинала API-эндпоинты есть, работающего UI не увидели — делаем честный.

## 5. FC27 Mobile — новый парсер скриншотов
- У елобота промпт заточен под FC Mobile (счёт, бомбардиры с минутами, пенальти).
- FC27: другие экраны статистики → новый `_AI_PROMPT`, свои примеры (few-shot),
  поле «бомбардир» опционально — по настройке создателя турнира (как ты и писал).
- Дедуп по sha256 скрина и матч-хэш (processed_screenshots) — берём из елобота.
- Если распознать не удалось — не «выберите вручную» голословно, а форма: счёт + кто забил
  (кнопки), валидация против состава клубов из БД.

## 6. Долги и Challenge Place
- Парсер: ссылка на тур → таблица результатов → сверка с нашими матчами → авто-долги.
- Пост «Долги по турам» в канал + ЛС-напоминания 3×/день (08:00/12:00/18:00 МСК) с тегами.
- Кнопка «оплатил» у админа → статус долга, журнал.

## 7. Трансферы
- Заявка в боте: клуб-продавец → цена → клуб-покупатель → подтверждение обеих сторон
  → одобрение админа → движение бюджета (калькулятор бюджета считаем из заявок+транзакций).
- Всё в мини-аппе на странице клуба: «Трансферное окно».

## 8. Админка в мини-аппе
- admin.js у оригинала уже вшит во фронт (84 КБ): сезоны, риск-лимиты, exposure, алерты.
- Включаем по `users.is_admin` + добавляем свои панели: долги, трансферы, генерация туров,
  ручной расчёт купонов, рассылка.

## 9. UX-отличия
- **Бренд клона: KURILKA SIGARKI** (решено 24.09). Валюту назовём на брендинге
  сессии 4 (рабочее имя — «монеты», константа в одном месте). Палитра: тёмная тема
  остаётся, акцент сдвигаем от золотого оригинала — варианты покажу в сессии 4.
- Тексты без «игрового» сленга оригинала где уместно; свои названия валют и званий.
- Push-уведомления ботом при: ставке, расчёте, дедлайне, трансфере, долге (оригинал молчит).
- Страница «Помощь/Правила» внутри аппа (оригинал не имеет вовсе).

## 10. Чего сознательно НЕ делаем
- Казино-модули Казимира, криптобиржа, банк-кредиты — вне скоупа.
- LLM-шутки в чат (елобот) — разве что отдельной фичей потом.
- Реальные деньги/вывод — только внутренняя валюта.
