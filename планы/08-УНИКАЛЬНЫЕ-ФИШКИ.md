# УНИКАЛЬНЫЕ ФИШКИ КЛОНА (выбрано 2026-09-24)

Принцип уникальности, сквозной для всего: **прозрачность и самостоятельная проверка** —
у оригинала кэфы, составы и решения админов чёрный ящик; у нас каждый может сам
проверить цифры, составы и историю. Плюс полноценная клубная жизнь, которой нет у оригинала.

Статус: всё ПОСЛЕ базы (сессии 11+), не вплетать в 1–10. Сезонный пропуск — отложен
и делается только по отдельной просьбе.

## A. Прозрачные ставки (сессия 11)

### A1. Публичная математика кэфов
- В карточке рынка кнопка «как получен кэф» → разбор: Elo клубов, форма, домашнее
  преимущество, маржа сезона → итоговые вероятности → кэф.
- История движения кэфа графиom (odds_history уже в схеме БД) — публично.
- «Наш кэф честный» = главный анти-аргумент против оригинала.

### A2. Value-подсветка
- Если рыночный кэф «отъехал» от расчётного → метка VALUE + простое объяснение
  («банк считает П1 34%, а наш расчёт 45%»).
- Использует тот же расчётный движок, что и генератор кэфов — одна правда.

## B. Клубы по-полной (сессии 12–13)

### B1. Состав клуба: загрузка и публичная проверка (база — сессия 6)
- Капитан загружает состав клуба (список игроков FC27) в «Мой Клуб».
- Страница клуба публична: состав, статистика (голы/ассисты/матчи из match_goals),
  история изменений состава — кто, когда, что поменял.
- **Каждый игрок может сам проверить** чужой состав и статистику — это фича доверия.
- Сверка составов с протоколами матчей (кто заявлен — тот и играл).

### B2. Трансферный маркетплейс карточек FC (сессия 8, база)
**Важно: на рынке торгуются КАРТОЧКИ игроков FC Mobile (виртуальные футболисты из
загруженного состава клуба), НЕ реальные участники.**
- Отдельная полноэкранная страница в аппе: лента лотов (карточка, позиция, OVR,
  клуб-продавец, цена или «аукцион»), поиск/фильтры по позиции и рейтингу.
- Лот = фикс-цена «купить сейчас» ИЛИ аукцион с таймером (см. B3).
- Переговоры: кнопка «написать в ЛС» (deeplink на продавца) + фиксация сделки в
  системе кнопками «предложить цену» → «принять/отклонить» — история видна админу.
- Обмены: деньги / игрок+деньги / игрок↔игрок с доплатой.
- На экране трансферов всегда виден баланс клуба (покупательной способности).
- Все сделки публичны и проверяемы: лента истории переходов по карточке и по клубу.

### B3. Аукцион карточек (сессия 12)
- Повышающие ставки клубами в реальном времени в боте: таймер, анти-снайпинг
  (продление при последней ставке), победитель платит из бюджета клуба.
- Анти-фейк: ставка = блокировка суммы на балансе клуба до конца аукциона.

### B4. Кастомизация клуба (сессия 12)
- Эмодзи-лого, два цвета клуба, девиз, название стадиона → видны в таблице,
  карточках матчей и на странице клуба. Палитра аппа подстраивается под матч
  (цвета двух клубов) — визуально непохоже на оригинал.

### B5. Спонсоры и стадион (сессия 13)
- Пассивный доход клуба: базовая посещаемость стадиона × результативность.
- Спонсорские контракты: условия («сыграть без поражений 3 тура» → выплата) —
  генерятся раз в сезон, капитан видит прогресс.
- Бюджет живёт: доходы/расходы/аукционы/штрафы — весь оборот в balance_history
  клубов и публичен.

## C. Отложено (только по отдельной просьбе)
- **Сезонный пропуск** (battle-pass с уровнями и ветками наград) — механизм не
  проектируем сейчас, только идея. Делать отдельным циклом сессий, если попросишь.

## D. Справочник игроков: Transfermarkt + свободные агенты (ОТЛОЖЕНО — после базы)

Идея пользователя: справочник игроков — по **Transfermarkt** (реальные футболисты),
со снимком **на определённую дату** (дату задаёт создатель сезона — обычно старт
сезона). В течение сезона реальные трансферы НЕ влияют — работаем по зафиксированному
снимку. Игрок сразу видит, кого может юзать; при выдаче клуба может проверить состав
(и по дате — состав на момент тура).

- **Свободные агенты — ключевое правило:** игрок принадлежит турнирному клубу только
  если его КУПИЛИ (запись владения в нашей БД). Если не куплен — он «свободный агент»,
  даже если на его карте указан реальный клуб (карта = данные из Transfermarkt,
  владение = наша БД). Свободного агента любой клуб может подписать без выкупа у клуба.
- **Данные:** официальный API у Transfermarkt отсутствует. Варианты: неофициальные
  API/скрейперы с GitHub, официальные альтернативы (API-Football, football-data.org —
  есть составы/игроки/фото), либо разовый ручной импорт. Снимок сохраняем в БД
  (players_directory: имя, позиция, клуб, возраст, фото, дата снимка).
- **Проверка состава:** автокомплит по справочнику при заявлении состава; загрузка
  состава СКРИНОМ → FC27-OCR сверяет со справочником; снимок состава на дату тура
  для разбора споров.
- RenderZ (база карточек FC Mobile) — запасной источник, если захотим OVR/карточный
  вид (его API тоже нет, но HTML парсится). Реальное решение за тобой при старте фичи.
