# logovo-clone — клон системы «Логово» (турнир + мини-апп)

Референс и разбор оригинала: `logovo-copy/` (фронтенд целиком, скрины, API-образцы, `ОБЗОР.md`).

## Структура
- `планы/` — планы исполнения:
  - `00-АРХИТЕКТУРА.md` — состав системы, схема БД, принципы
  - `01-ФУНКЦИИ-МИНИАППА.md` — каждая функция оригинала + решение (сохранить/менять/добавлять)
  - `02-БАЗА-ДЛЯ-ЗАИМСТВОВАНИЯ.md` — что реально работает у елобота/Дракобета, что мёртвое
  - `03-УЛУЧШЕНИЯ-ПРОТИВ-ОРИГИНАЛА.md` — чем отличаемся и что продумываем сами
  - `04-СЕССИИ.md` — работа по сессиям 1–10 + чек-лист
- `бот/` — Python-основа: PTB-бот + aiohttp-мини-апп в одном процессе
  - `db_backend.py`, `elo.py` — скопированы из елобота (реально работающие модули)
  - `db.py` — схема: ядро елобота + лига клубов + ставки
  - `main.py` — точка входа, `config.py` — env-конфиг
- `миниапп/` — сервер мини-аппа: статика + `/api/*` с проверкой подписи Telegram
  - фронт портируем из `logovo-copy/src/` в `миниапп/static/` (сессия 4)

## Запуск (сессия 1)
```
cd бот
cp .env.example .env   # вписать BOT_TOKEN
pip install -r requirements.txt
python main.py         # поднимет polling бота + http://localhost:8080/app
```

## Правила
- Секреты только в `.env` (у елобота ключи утекли в репозиторий — не повторять).
- Каждая сессия = коммит + отметка в `планы/04-СЕССИИ.md`.
